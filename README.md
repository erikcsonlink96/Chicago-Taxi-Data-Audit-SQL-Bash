# Chicago Taxi - Data Integrity & Troubleshooting Audit 📊

**"Garantizando la transparencia operativa mediante el análisis profundo de datos y servidores."**

### 📌 Impacto de Negocio
Este proyecto demuestra mi capacidad de **Análisis de Causa Raíz (RCA)**. Al auditar directamente la base de datos y los logs del servidor, garantizo que la información del negocio sea íntegra y consistente, detectando discrepancias críticas de data que las pruebas de UI tradicionales no pueden visualizar.

### 🛠️ Tech Stack
- **Bases de Datos:** SQL (SQLite / PostgreSQL)
- **Operaciones:** Bash / Linux Terminal
- **Análisis:** SQL Queries avanzadas (Joins, Cast, CTEs)

### 🚀 Capacidades Técnicas
- **Troubleshooting de Servidor:** Navegación y auditoría de archivos de sistema mediante comandos Bash.
- **Consultas Complejas:** Uso de `INNER JOIN`, filtros temporales y funciones de agregación para extraer insights sobre la operación de taxis.
- **Integridad de Datos:** Verificación de la consistencia de los registros de viajes y pagos contra las reglas de negocio establecidas.
